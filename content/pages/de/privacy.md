Noah Reviews ist eine statische Website. Wir verwenden keine Cookies, keine Analyse-Tracker, keine Werbenetzwerke und keine Anmeldeformulare.

Die Website wird auf GitHub Pages gehostet. GitHub kann dabei aus Sicherheitsgründen grundlegende technische Daten wie IP-Adressen protokollieren. Produktbilder werden von den Bildservern unseres Partners (Shopify) geladen, die beim Ausliefern eines Bildes die üblichen Anfragedaten erhalten.

Wenn du auf einen Partnerlink klickst, gilt auf dessen Website die Datenschutzerklärung des Partners.
